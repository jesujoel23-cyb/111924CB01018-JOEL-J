# Factorial of a Number

## Problem Statement

Write a Python program to find the factorial of a given number.

The factorial of a number is the product of all positive integers from `1` to that number. It is represented by the symbol `!`.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## Input

```text
Enter a number: 5

```

## Output

```text
Factorial of 5 = 120

```

## Explanation

For the given number `5`, the factorial is calculated as:

```text
5 × 4 × 3 × 2 × 1 = 120
```

Therefore, the factorial of `5` is `120`.

## Algorithm

1. Get a number from the user.
2. Initialize the factorial value as `1`.
3. Use a loop from `1` to the given number.
4. Multiply each number with the factorial value.
5. Display the calculated factorial.

## Technologies Used

* Python
* Python `for` loop
* Variables
* User Input

## How to Run

Open a terminal in the project folder and run:

```bash
python factorial.py
```

Enter the number when prompted.
