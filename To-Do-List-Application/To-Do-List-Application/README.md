# To-Do List Application

A responsive task-management web application built with **HTML, CSS, and vanilla JavaScript**. It helps users organise daily activities by adding tasks, marking them complete, filtering the list, and deleting tasks.

## Features

- Add tasks with a simple input form.
- Mark tasks as completed or pending using the checkbox or green action button.
- Delete tasks individually.
- Filter the list by **All**, **Pending**, and **Completed**.
- View live task totals and pending/completed summaries.
- Automatically save tasks in browser `localStorage` so they remain after a page refresh.
- Responsive layout for desktop, tablet, and mobile screens.
- Accessible labels and keyboard-friendly form controls.

## Technologies Used

- HTML5 — page structure
- CSS3 — responsive styling and layout
- JavaScript — DOM manipulation and task operations
- Browser Local Storage — persistent task data
- Git & GitHub — version control and project hosting

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a modern web browser.
4. Add a task, mark it complete, switch filters, or delete it.

No server, package installation, or API key is required.

## GitHub Submission

Create a new public repository named `To-Do-List-Application`, then run these commands from the project folder:

```bash
git init
git add .
git commit -m "Build responsive To-Do List application"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/To-Do-List-Application.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Add the repository URL to your assignment submission after pushing.
